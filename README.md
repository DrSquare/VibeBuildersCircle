# VibeBuildersCircle

This repository is used to share **presentation slides** and **sample prompts** for the monthly **Vibe Builders** session.

## Purpose

The goal of this repo is to keep session materials in one place so members can:

- Access slide decks from each monthly session
- Reuse and adapt sample prompts
- Collaborate on ideas between meetings

## What you'll find here

- `slides/` — Presentation decks and supporting visuals
- `prompts/` — Prompt examples, templates, and experiments
- `notes/` *(optional)* — Session notes, follow-ups, and references

## Contributing

Contributions are welcome. You can:

- Add new monthly slide decks
- Share prompts that worked well
- Improve prompt clarity with context and expected outcomes

## Session cadence

Materials are updated for each **monthly Vibe Builders session**.
